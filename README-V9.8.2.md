# BODY OS V9.8.2 — Progress Photo Upload + Session Muscle

## Séance
Le muscle sélectionné est désormais affiché explicitement sous le titre SÉANCE,
avec le nombre d'exercices et la durée estimée.

## Photos d'évolution
La popup statique devient un gestionnaire de photos :
- import depuis téléphone / ordinateur ;
- import multiple ;
- remplacement ;
- suppression ;
- date modifiable ;
- timeline ;
- comparaison avant / maintenant ;
- compression côté navigateur ;
- persistance locale.

Les photos importées sont automatiquement reprises dans les aperçus Progress.

Important : cette V9.8.2 conserve les acquis de V9.8.1 et V9.7.
