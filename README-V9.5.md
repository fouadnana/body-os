# BODY OS V9.5 — Nutrition Content + Toast Fix

Cette version part de la V9.4 validée techniquement.

## Nutrition
Chaque repas indique désormais directement son contenu :
- Petit déjeuner : Skyr 0%, flocons d’avoine, myrtilles, beurre de cacahuète
- Déjeuner : saumon, riz basmati, brocoli, citron
- Goûter : Skyr 0%, fruits rouges, miel, amandes
- Dîner : poulet grillé, patate douce, légumes verts

Le détail du repas affiche également cette composition avant les macros.

## Correction UI
Le message du bouton `+` devient un toast court et non bloquant :
`Ajout rapide prêt`.

Il disparaît automatiquement après 1,8 seconde et ne recouvre plus / ne bloque plus
la bottom navigation.

La V9.5 ne modifie pas le Golden Today, la navigation musculaire Workout,
ni la navigation musculaire Progress.
